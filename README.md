# DailyBit

Toss Securities의 밀도감과 데스크톱 정보 구조를 참고해 구성한 **적립식 디지털 자산 투자 상품 상세 페이지 UI 시안**입니다.

## 포함된 화면

- 데스크톱 상단 내비게이션과 검색 영역
- 비트코인·이더리움 균형 적립 상품 요약
- 최근 1년 투자 성과 차트
- 자산 구성, 5년 예상 결과, DailyBit 리포트
- 적립 설정 요약, 주요 자산 시세, 투자 위험 안내

모든 버튼과 수치는 시각적 프로토타입용이며 실제 주문·검색·로그인 기능은 연결되어 있지 않습니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
